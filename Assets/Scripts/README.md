# Prototype controls

Press Play in `Assets/Scenes/SampleScene.unity` to create the temporary test room.

- Move: `A/D` or left/right arrow keys
- Jump: `Space`, `W`, or the up arrow key
- Shoot: `J`, `X`, or right `Ctrl`
- Crouch / drop through: hold `S` or the down arrow
- Ladder up: hold `Space`, `W`, or the up arrow while inside a ladder
- Ladder down: hold `S` or the down arrow while inside a ladder

The level is generated by `PrototypeLevelBootstrap` at runtime. The white-square sprite
and platform coordinates are intentionally temporary; replace them with authored sprites,
prefabs, or Tilemap geometry when the visual direction is ready.

The player's child object named `ProjectileSpawnPoint` is the muzzle position. Its default
offset is `(0.58, 0.08)`, and it is the first place to adjust when the player artwork is added.

Jump progression is controlled by `PrototypePlayerController`:

- Initial setting: `maxJumps = 1`
- Double jump: call `UnlockDoubleJump()` or `SetMaxJumps(2)` from an item or event
- Add one more jump: call `AddExtraJump()`
- Unlimited jump: call `SetUnlimitedJump(true)`
- Restore the initial state: call `ResetJumpUpgrades()`

Stage gimmicks are generated into `Assets/Prefabs/Gimmicks` by
`Prototype > Generate Prototype Prefabs`:

- `OneWayPlatform`: pass through from below, but cannot be dropped through.
- `DropThroughPlatform`: crouching lets the player pass downward.
- `BreakablePlatform`: breaks after landing; `respawn` is enabled by default.
- `MovingPlatform`: choose horizontal or vertical movement, speed, range, and end wait.
- `Ladder`: climb with the ladder controls above.

Player crouching is configured on `PrototypePlayerController`. It stops horizontal
movement, shrinks the collider, and lowers the projectile spawn position.

`LoopingBackground.prefab` is generated into `Assets/Prefabs/Background`. Place one
instance in the scene. Its `tileSize`, horizontal/vertical loop switches, follow factor,
and sorting order are adjustable from the Inspector. The camera's Background Color still
acts as the fallback color behind the tiles.

`SceneDoor.prefab` is generated into `Assets/Prefabs/Gimmicks`. Set a unique `Door Id`,
the destination scene name, and the destination door id. Pairing two doors by these ids
places the player at the matching door's `ArrivalPoint` when travelling in either direction.
The `Fallback Spawn Position` is used when no matching destination door is found. Scenes
must be included in Build Settings for `SceneManager.LoadScene` to load them.
