# Prototype controls

Press Play in `Assets/Scenes/SampleScene.unity` to create the temporary test room.

- Move: `A/D` or left/right arrow keys
- Jump: `Space`, `W`, or the up arrow key
- Shoot: `J`, `X`, or right `Ctrl`

The level is generated by `PrototypeLevelBootstrap` at runtime. The white-square sprite
and platform coordinates are intentionally temporary; replace them with authored sprites,
prefabs, or Tilemap geometry when the visual direction is ready.

The player's child object named `ProjectileSpawnPoint` is the muzzle position. Its default
offset is `(0.58, 0.08)`, and it is the first place to adjust when the player artwork is added.

Jump progression is controlled by `PrototypePlayerController`:

- Initial setting: `maxJumps = 1`
- Double jump: call `UnlockDoubleJump()` or `SetMaxJumps(2)` from an item or event
- Add one more jump: call `AddExtraJump()`
- Unlimited jump: call `SetUnlimitedJump(true)`
- Restore the initial state: call `ResetJumpUpgrades()`
